# multi-threading

Learning multi-threading concepts through examples.

## Examples

| # | Name | Topic |
|---|------|-------|
| 01 | Greeting | Create threads and wait for them to finish |
| 02 | Partial Sum | Split work across threads and collect results |
| 03 | Mutex Counter | Protect shared data from race conditions |

## Build & Run

### C++

```bash
bash scripts/run_cpp.sh examples/<example-folder>
```
